## 같은 중심압력으로 비교하면 같은 질량의 별인가?

EOS를 바꾸고 중심압력은 유지했다. 질량도 유지된다는 보장이 있는가? 없다면 무엇을 다시 조절해야 하는지 먼저 적자.

먼저 한두 문장으로 답한 뒤 아래 설명을 읽자. 첫 예측이 틀렸거나 아직 모르겠다고 적는 것은 감점하지 않는다.

## 필요한 관계와 읽을 위치

$F(P_c)=[M(P_c)-M_*]/M_*$. 좁은 $P_c$ bracket과 작은 $|M-M_*|$는 다른 조건이다.

- `learner/src/structure/ns_target_mass.f90`
- `notes/chapters/ch03_tov.md`

## 계산으로 옮기기

기본 경로는 제공 함수의 호출과 해석이다. 아래 `learner` 시험은 같은 물리 함수를 직접 작성한 경우에 실행한다. 제공 예제를 검사할 때에는 명시적으로 `calculation`을 선택한다.

1. 허용 중심압력 구간과 branch를 선택하고 scan한다.
2. TOV 실패를 외부 root의 정상 함수값으로 사용하지 않는다.
3. 선택한 목표질량에 대한 외부 bisection을 연결한다.
4. 최종 Pc에서 TOV를 다시 풀고 mass_atol/mass_rtol을 확인한다.

## 결과를 설명하기

최종 중심압력에서 별을 다시 적분한 질량 잔차가 필요하다. 외부 bracket이 좁다는 사실만으로 내부 TOV 오차까지 제거되지는 않는다.

**남길 증거.** Pc–M scan; 최종 질량 잔차와 branch 식별; EOS 변화 시 Pc가 달라져야 하는 이유

**판단 기준.** 2점 예: 재적분 질량 오차를 보고하며 root bracket만으로 same-mass를 선언하지 않는다. 최초 예측의 정오보다, 결과를 본 뒤 이유를 고치고 다른 입력에도 적용하는지를 본다.

## 막혔을 때

**힌트 1.** 외부 root와 내부 TOV의 종료 상태를 별도로 저장한다.

**힌트 2.** turning region을 가로지르는 bracket이 다중해를 숨기는지 점검한다.

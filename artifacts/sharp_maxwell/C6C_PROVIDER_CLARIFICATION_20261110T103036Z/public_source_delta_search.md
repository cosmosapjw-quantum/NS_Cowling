Conclusion: **no additional primary-source material defining the fields was found.** The only new public material is the RELATED sibling product, which shows that in uniform core rows the provider stores nucleons in pair fields and zeros the nuclear group, whereas crust rows store Yn=Yp=0 with a nonzero group. Whether that implies a "whole-cell in the group" convention is not inferred here; it is a question for the provider.

## 음향시간을 추가하면서 원래 별을 바꿔야 하는가?

첫 저장 반경이 0이 아니다. 누적 적분을 그곳에서 0으로 시작하면 무엇을 생략하는지 먼저 그림이나 문장으로 설명하자.

먼저 한두 문장으로 답한 뒤 아래 설명을 읽자. 첫 예측이 틀렸거나 아직 모르겠다고 적는 것은 감점하지 않는다.

## 필요한 관계와 읽을 위치

$$
\tau(r)=\int_0^r\frac{e^{\lambda(r')-\nu(r')}}{c\sqrt{\chi(r')}}\,dr'.
$$
$0<r<r_0$에서는 첫 integrand를 유지하고, 이후에는 저장된 radial 점의 trapezoid rule을 적용한다.

- `extensions/P5/cumulative_acoustic_time.py`
- `notes/chapters/ch12.md`

## 계산으로 옮기기

고급 solver를 바꾸지 않는 작은 진단 확장이다. 독립 폴더의 P5 함수만 작성하고 기존 배경과 진동식은 그대로 둔다.

1. 현재 독립 export 안의 P5 slot만 수정한다.
2. 중심 누락구간의 hold와 이후 trapezoid 규칙을 구현한다.
3. 상수 integrand와 비균일 격자의 비상수 integrand를 각각 확인한다.
4. 잘못된 chi/반경 입력을 거절하고  solver source hash를 보존한다.

## 실행해서 무엇을 볼 것인가

패키지 루트에서 실행한다. `--plan`은 경로만 확인하며 계산 성공을 뜻하지 않는다.

```bash
python tools/run_assignment.py P5 --plan
python tools/run_assignment.py P5 --run \
  --workspace learner --output ../P5_result.json
```

## 결과를 설명하기

배경을 읽기만 하는 진단이다. 중심 누락 구간의 규칙과 각 반경 간격을 명시하고, 상수 integrand 하나로 일반 적분 구현을 검증했다고 말하지 않는다.

**남길 증거.** cumulative τ CSV와 metadata; 두 독립 적분 기준의 시험 결과; 허용 변경 경로와 이전 solver 불변 receipt

**판단 기준.** 2점 예: 비상수 g의 비균일 격자에서도 중심 hold와 trapezoid를 독립 계산으로 확인한다. 최초 예측의 정오보다, 결과를 본 뒤 이유를 고치고 다른 입력에도 적용하는지를 본다.

## 막혔을 때

**힌트 1.** 처음 저장된 반경이 0이 아니므로 초기 τ를 0으로 두면 안 된다.

**힌트 2.** 간격이 균일하다고 가정하지 말고 각 Δr을 사용한다.

# 세 계열 sharp Maxwell 생성

## 고정된 요청과 출처

2026-11-17 요청은 등록된 crust 13종과 core 5종의 모든 같은 계열 조합을 실제로 평가하는 것이다. 기준 커밋은 `59183fcd62c91aa1506ad1608965d2c52950e2ee`이며, 이전 sharp Maxwell 분기 `f46fdd5ea10ee83582f6be8b4ec851b234895ea1`(2026-11-11)의 관련 구현과 비교하였다. 모델 쌍은 계열마다 65개, 총 195개다. 물리적으로 존재하지 않는 접합을 생성 성공으로 간주하지 않는다.

계열은 `native_generated`, `public_original`, `public_reconstructed`로 고정한다. 서로 다른 계열의 결합은 허용하지 않는다. 공개 원본은 공급자 바이트와 해시를 보존한다. 형식과 기준 질량의 가역적 표현 변환은 실제 에너지 변경과 구분한다. 공개본을 토대로 매개변수를 추정한 후 생성기를 실행한 SPG는 생성기 계열에 속한다.

## 실행과 판정

1. 최신 원본 18종을 확보하고 native 생성 결과 18종의 실제 수렴·지원 구간과 영수증을 조사한다.
2. sharp Maxwell 구현의 원본 행 변경, phase 바깥 행 누락, 실패 분류·보고 결함을 회귀 예제로 재현하고 수정한다.
3. 공개 EOS의 열역학 불일치를 개별 진단한다. reconstruction은 문제를 확인한 열역학 관계만 복구하며 핵 매개변수, 입자종, 에너지 기준을 재적합하지 않는다. 이미 일관된 구간은 그대로 유지한다. 원본과 재구성본은 별도 파일과 해시를 가진다.
4. 공급자 crust가 포함된 공개 core 표에서는 실제 core의 정의역을 선택한다. 안정성·인과성이 깨지는 구간이나 미해결 내부 phase 경계를 가로질러 보간하지 않는다. 정의역 제한은 상대 EOS나 교차점 존재 여부에 의존하지 않고 먼저 기록한다.
5. 동일 계열의 65개 모델 쌍을 각각 실행한다. 필요한 경우 독립적으로 정한 유효 연결 구간의 조합도 모두 기록한다. Fortran kernel에서 접합을 계산하고 직렬화된 표에서 압력·화학퍼텐셜·잠열 항등식을 별도로 재검산한다.
6. 결과는 실제 생성, 공통 지지구간 없음, 평형 교차점 없음, 다중 교차·방향 문제, 원본 열역학 또는 보간 문제, 실행환경 문제로 구분한다. 제한된 입력에서 실패한 것을 EOS 전체의 불가능성 정리로 확대하지 않는다.

## 물리 계약

찬 국소 중성 물질에 대해 `P_low(mu_t)=P_high(mu_t)`, `mu_low=mu_high=mu_t`, `n_high>n_low`, `Delta epsilon=mu_t Delta n`을 요구한다. 각 매끈한 가지의 `n=dP/dmu>0`, `dn/dmu>0`, `0<c_s^2/c^2<=1`을 검사한다. 상대적 에너지 오프셋을 맞춰 교차점을 만들지 않는다. 단위는 `n: fm^-3`, `P,epsilon: MeV fm^-3`, `mu: MeV`다.

출력의 core–crust 접합 검증과 입력에서 물려받은 외피·기존 내부 phase 경계의 검증은 별도다. 외피나 고밀도 core가 제한된 결과를 전 밀도 또는 별 표면까지 완비된 EOS로 부르지 않는다. 원본의 알려진 문제를 유지한 산출물은 재구성본이나 완전 검증본으로 표시하지 않는다.

## 산출물

재실행 가능한 생성 스크립트, 출처·정의역·수정량 영수증, 195개 모델 쌍의 결과 행렬, 성공한 각 접합의 CoMPOSE 표와 독립 검산 결과, 계열별 압축 파일, 실패 원인의 보존, 실제 테스트 로그 및 코드·바이너리 SHA를 남긴다. 이전 작업의 영수증과 원본 데이터는 수정하지 않는다.

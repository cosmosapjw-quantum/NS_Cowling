For APR, the superluminal tail begins near `n_B = 0.88 fm^-3` and reaches approximately `c_s^2 = 1.47`. For KDE0v1 it begins near `1.442943 fm^-3` and reaches approximately `1.107`. All three derivative schemes reproduce the superluminal behavior. The numerical spread in the maximum is small compared with the excess above unity; this is not a one-scheme interpolation artifact.

## Matched-tail identity test

For every failed directory, the audit located `nb_transition_right_fm3` and compared the remaining matched-core arrays with the source core arrays. All 156/156 failed cases preserve the source tail in `n_B`, `P`, and `epsilon` within the declared tight floating-point tolerances. This establishes provenance of the failing segment, rather than merely correlating the failure with a source model name.

## Physical, numerical, matching, and implementation attribution

- **Source/model physics:** The supplied APR and KDE0v1 tables, as represented over their full tabulated high-density ranges, violate relativistic causality. This says the *selected tabulated model/extrapolation* is acausal there. It does not establish that the true neutron-star EOS is acausal; the microscopic model may not be valid to those densities.
- **Numerics:** PCHIP, natural cubic spline and centered finite differences all identify the same superluminal tails. There is no evidence that the 156 FAIL count is generated by a derivative-scheme choice.
- **Crust-core matching:** The 156 failed tables have a matching-to-core tail equality proof. Cross-model saturation-property mismatch can still be a source of physical systematic uncertainty in the junction, but it is not the cause of these C10 failures.
- **Implementation:** The independent re-read and consistency re-evaluation reproduce the saved status. No code exception, malformed EOS, or metadata disagreement accounts for the 156 failures.

## Optional causal completions are separate models

A maximally stiff or constant-sound-speed extension is not a correction uniquely implied by the microscopic table. It changes the high-density model and must be recorded as such.

- APR_APR with a CSS tail `c_s^2 = 0.95` matches at `n_B = 0.873272 fm^-3`; its full gate passes and PCHIP, cubic-spline and centered-FD maxima are approximately 0.9818, 0.9953 and 0.9809. This is a robust causal **alternative model**, not the original APR EOS.
- KDE0v1 with a CSS tail `c_s^2 = 0.80` passes the package finite-difference hard gate, but independent PCHIP and cubic-spline profiles still register approximately 1.00095 and 1.03225 near the join. It is therefore **diagnostic-only and not promoted**. The source onset is too close to the interpolation-sensitive join for this particular completion recipe to be called robust.

## Conclusion

The correct resolution is to preserve the original 156 FAIL classifications, report their source provenance, and expose optional causal-completion variants with independent scheme validation. Reclassifying the original APR/KDE0v1 tables as PASS by clipping `c_s^2`, deleting their high-density points, or altering their tail would conceal rather than resolve the input-model limitation.

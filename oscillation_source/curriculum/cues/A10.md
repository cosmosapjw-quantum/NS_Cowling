# A10 · 두 근에서 f와 p1 모드로

**선행:** A09　 **독립 작업:** 6–10시간 (계획치)

## 두 번째로 찾은 근은 반드시 첫 압력모드인가?

주파수 순서만 적힌 표에서 두 모드의 이름을 지운다. 다시 이름을 붙이려면 고유함수에서 무엇을 읽어야 할지 먼저 고르자.

먼저 한두 문장으로 답한 뒤 아래 설명을 읽자. 첫 예측이 틀렸거나 아직 모르겠다고 적는 것은 감점하지 않는다.

## 필요한 관계와 읽을 위치

$x=r/R_s$, $w=W/R_s^3$, $v=V/R_s^2$, $\int(w^2+6v^2)\,dx=1$. 이 정규화는 진단량이며 mode energy가 아니다.

## 계산으로 옮기기

기본 경로는 제공 함수의 호출과 해석이다. 아래 `learner` 시험은 같은 물리 함수를 직접 작성한 경우에 실행한다. 제공 예제를 검사할 때에는 명시적으로 `calculation`을 선택한다.

1. coarse 배경에서 scan과 bracket을 만든다.
2. 정밀 root에서 profile을 재적분하고 W,V의 내부 node를 확인한다.
3. 교정된 smooth_l2 contract와 fixed background의 identity를 함께 읽는다.
4. ODE tolerance와 배경 해상도의 영향을 따로 비교한다.

## 결과를 설명하기

이 예제에서는 node와 overlap을 지정된 정규화·구간에서 비교한다. 두 곡선의 높이 차이를 물리 에너지의 차이로 읽었다면 정규화부터 다시 확인한다.

**남길 증거.** root_status와 identity_status; 같은 좌표/정규화의 f,p1 고유함수; 적분 방법 일치와 배경 오차의 차이

**판단 기준.** 2점 예: 배경 refinement 차이가 root tolerance보다 큰 사례를 제시하고 오차원을 올바르게 분류한다. 최초 예측의 정오보다, 결과를 본 뒤 이유를 고치고 다른 입력에도 적용하는지를 본다.

## 막혔을 때

**힌트 1.** node zero threshold와 endpoint 제외구간을 먼저 고정한다.

**힌트 2.** 0/0 및 1/1 규칙은 현재 smooth family의 진단이지 계면 spectrum의 보편 정리가 아니다.

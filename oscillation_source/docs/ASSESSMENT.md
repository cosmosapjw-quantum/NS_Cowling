# 무엇을 설명하고 남길 것인가

우리는 코드를 실행한 사실과 물리적 판단을 함께 보되 같은 점수로 대신하지 않는다. 제공 함수를 호출해도 된다. 중요한 것은 무슨 문제를 풀었는지, 반환된 증거가 어떤 결론을 허용하는지 설명할 수 있느냐는 것이다.

## 처음의 예측은 채점하지 않는다

계산 전에 짧게 예상하고, 모르는 부분은 모른다고 적는다. 처음의 답이 틀렸다고 감점하지 않는다. 풀이와 계산을 본 뒤 생각을 어떻게 고쳤는지, 어떤 근거를 썼는지 평가한다. 사용하는 힌트를 숨길 이유도 없다. 힌트가 필요한 지점을 알아야 다음 설명을 정할 수 있다.

## 다섯 가지 증거

| 판단할 것 | 충분한 증거 | 아직 부족한 예 |
|:--|:--|:--|
| 문제의 정의와 수정된 예측 | 입력·가정·물리량을 정하고 예상이 바뀐 이유를 설명한다. | 출력 숫자의 이름만 적는다. |
| 계산 | 단위·함수·실행 결과가 같은 문제로 연결된다. | 시험 통과 문구만 붙인다. |
| 비교 | 무엇을 고정하고 바꿨는지 밝히고 독립 기준과 대조한다. | 서로 다른 표면의 주파수를 같은 정답으로 비교한다. |
| 진단 | 관찰한 오류와 가능한 원인을 구별하고 다음 실험 하나를 고른다. | 모든 차이에 tolerance 감소만 제안한다. |
| 결론의 범위 | 확인된 사실과 아직 확인되지 않은 물리를 구별한다. | 작은 잔차로 모델 전체가 옳다고 주장한다. |

각 항목은 근거가 없거나 핵심 의미가 틀리면 0, 맞는 요소는 있지만 조건·이유가 불완전하면 1, 관계를 설명하고 작은 새 입력에도 적용하면 2로 기록한다. 숫자만 돌려주지 않고 다음에 다시 할 작업 하나를 적는다. 모든 과제를 이 다섯 항목의 장문 보고서로 만들 필요는 없다. 큐시트의 증거를 짧게 남기면 된다.

## 설명이 막혔을 때

적분 성공을 고유값 발견으로 읽거나, 작은 잔차를 주파수 정확도의 충분조건으로 읽거나, 선형 고유함수의 임의 진폭을 모드 에너지로 읽는 경우에는 해당 사례를 다시 살펴본다. 다른 항목의 높은 점수가 그 오해를 없애지는 않는다. 정의를 가리키는 힌트, 작은 반례, 함께 푼 한 단계를 순서대로 사용하고 다음 입력에서 재시도한다.

코드는 맞고 설명이 틀린 경우에는 개념 질문을 한다. 물리는 이해했지만 코드가 실패한 경우에는 가장 작은 입력에서 변수 전달을 추적한다. 설치·권한·시간제한 문제는 별도로 적는다. 학생이 통제할 수 없는 실행 문제를 개념 이해의 실패로 채점하지 않는다.

## 도움 없이 다시 확인하기

다음 만남에는 큐시트의 짧은 질문에 먼저 답한 뒤 본문과 자신의 기록을 열어 확인한다. 이것은 무조건 공식을 외우는 시험이 아니다. 같은 원리를 다른 입력이나 표현에 쓸 수 있는지 보기 위한 것이다. 낯선 고급 수치 방법의 내부를 구현하는 일은 기본 성취가 아니며, 제공 방법의 입력·가정·반환 상태를 해석하는 능력은 기본 성취다.

강의의 수료, 코드 실행의 재현, 수치 검증, 독창적 논문 기여는 별도로 판단한다. 실제 학습 효과는 학생의 응답과 이후 독립 수행을 관찰한 뒤에만 말할 수 있다.

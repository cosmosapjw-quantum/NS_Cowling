# BPS·NV 지각 EOS 재구성과 32개 코어 접합 시험

2026-11-24 · **Reconstructed EOS** · 기준 코드 b49d44bc0b2c774f4bd81ed6753f3795abddca6b

기존 기록에서 입력 부족으로 실행하지 못한 672개 조합을 실제 Fortran matcher로 시험했다. 32개는 19개 모형명에 대응하는 서로 다른 코어 입력이며 동일한 모형명의 다른 표현도 구분했다. 대표값은 BPS 외각 132/224, NV 인쇄 계수 고정조성 0/224, NV 조건부 수정 계수 고정조성 0/224다. 별도로 BPS 외각에 NV1973 저자의 내각 fit을 붙이면 138/224가 열역학 검사에 통과한다. 이 중 115개 결과에 외각과 내각이 모두 들어 있다.

## 1. 결측 입력을 채운 방법

**BPS 외각.** 기존 Myers–Świątecki Fortran 생성기에 1971년 BPS Table 1의 핵종 후보 130개와 1964 MTW 평가 질량을 읽는 경로를 추가했다. 23개는 평가 질량, 107개는 1966년 식으로 생성한 질량을 썼다. 23개의 선택에는 평가 질량의 표준오차를 이용한 근사가 포함된다. 압력이 주어질 때 상대론적 전자 기체와 bcc 격자를 포함한 핵자당 Gibbs 에너지를 최소화했다. 601개 압력점과 11개 상전이 양쪽의 22개 상태가 623행을 이룬다. BPS Table 2의 평형 핵종 12개가 순서대로 재현됐고, 독립 Python 계산과 모든 행의 핵종이 일치했다. 최대 압력 상대차는 $3.75\times10^{-11}$이다. 중성자 방출점에서 $n_B=2.5869117161\times10^{-4}\,\mathrm{fm}^{-3}$, $P=4.9087525474\times10^{-4}\,\mathrm{MeV\,fm}^{-3}$다. CompOSE #68 외각의 겹치는 43개 행에서 같은 밀도의 압력 절대 상대차 중앙값은 0.00323%, 최대는 27.59%로 얕은 철층에서 나왔다. 인쇄 Table 5에 대한 같은 통계는 0.01489%, 3.477%다. 1965년 질량 파일과의 행별 동일성은 미확인이다. [BPS 1971](https://doi.org/10.1086/151216) · [MTW 질량 평가](https://doi.org/10.1016/0029-5582(65)90114-8) · [Myers–Świątecki 1966](https://doi.org/10.1016/S0029-5582(66)80001-9) · [CompOSE #68](https://compose.obspm.fr/eos/68)

**NV 내각의 두 재구성.** NV1973의 벌크 함수와 NV1972 Table I의 $B,C,D$를 기존 Fortran 셀 에너지에 넣었다. 인쇄본 그대로 쓴 경우와 대칭 계수 $D_{03}=D_{30}$ 두 항에만 100을 곱한 경우를 각각 실행했다. 준고전 계산에서는 중성자·양성자 밀도 대비를 따로 변화시키고 운동에너지 밀도에 Thomas–Fermi 항과 $ |\nabla\rho|^2/(36\rho)$ 보정을 사용했다. Table 3의 11개 조성점에서 원문 평형 에너지와의 최대 편차는 핵자당 1.109, 0.996 MeV였다. 두 모델에서 각각 1개, 2개 저밀도 계산점이 음압을 냈다. 접합 입력은 마지막 셀 $N=950, Z=32$를 압축한 $0.0475\le n_B\le0.0789\,\mathrm{fm}^{-3}$의 49개 상태만 사용했다. 물리적 $Y_q=32/982$ 및 약반응 친화도 약 1.15–11.66 MeV를 기록했다. 두 표는 조성 제약을 포함한다. [NV1972](https://doi.org/10.1103/PhysRevC.5.1472) · [NV1973](https://doi.org/10.1016/0375-9474(73)90349-7)

**계수에 대한 원전 교차검산.** $\rho_n=\rho_p=0.080\,\mathrm{fm}^{-3}$에서 NV1972 식 (6.12)의 두 계수는 인쇄값으로 $(1276.86246,-522.39857)$, 조건부 수정값으로 $(381.10547,15.05562)\,\mathrm{MeV\,fm^5}$다. 후자는 같은 논문 Table II set 1의 ((381.1,15.1))에 인쇄 정밀도로 일치한다. 비대칭 set 2는 인쇄된 (B)의 평균 조합이 0.033% 이내로 일치하지만 개별 $t_1,t_2$는 재현되지 않고 식 (6.14)의 역산에도 계수 불일치가 있다. Negele (1970) Table IV의 방사형 상호작용을 적분해 Table V(a)의 직접항 모멘트 네 개를 0.181%, 교환항 비 두 개를 0.0234% 이내로 검산했다. 이 경로는 대칭점에서 $D=132.53\,\mathrm{MeV\,fm^5}$를 주며 NV72 수정과 인쇄값은 각각 167.81, 839.62다. 스핀 평균, 유한 표의 끝점과 미공개 피팅 가중치가 있어 정확한 계수 덱 복원으로 해석할 수 없다. [Negele 1970](https://doi.org/10.1103/PhysRevC.1.1260) · [NV1972 식 (6.12), Tables I–II](https://doi.org/10.1103/PhysRevC.5.1472)

## 2. 원래 672개 조합의 결과

각 표 칸의 분모는 32개 코어 입력이다. 통과는 matcher가 생성한 후보가 재독출과 보존된 지각 행의 압력·제1법칙 필요조건 검사를 통과했다는 뜻이다. 1개 조합에 여러 상 구간을 시도할 수 있다. 접합법끼리 같은 코어를 통과해도 별도 조합으로 센다.

| 입력 | 제1법칙 Hermite | cubic F | quintic F | cubic P | quintic P | CSS | Maxwell | 합계 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 재구성 BPS 외각 | 17 | 23 | 23 | 23 | 23 | 23 | 0 | 132 |
| NV 인쇄 계수, 고정 조성 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| NV 수정 계수, 고정 조성 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 추가 비교용 BPS + 보간 + NV 저자 fit | 23 | 23 | 23 | 23 | 23 | 23 | 0 | 138 |

BPS 외각과 32개 코어에서 허용한 34개 Maxwell 후보 구간은 압력 지지구간이 모두 분리돼 있다. 가장 낮은 공개 코어 압력도 $0.00336979\,\mathrm{MeV\,fm}^{-3}$다. BPS 보간 통과 132개 중 30개가 외각 12개 상을 모두 포함한다. 공개 결과의 보간 끝점 밀도비는 23.19에서 $3.34\times10^7$까지다. CSS의 공개 통과 22개는 모두 첫 BPS 상전이 이전에서 기존 표를 떠난다. 따라서 외각 단독 통과율을 내각의 검증으로 사용할 수 없다.

두 고정조성 NV 원자료에서 matcher는 $Y_q$ 축 또는 전하·렙톤 규약이 코어의 베타평형 규약과 다름을 검출했다. 이는 접합 창 탐색 전의 실제 Fortran 반환값이다. 추가 시험에서 독립적인 화학퍼텐셜을 1변수 엔탈피로 바꿔도 물리적 $Y_q$ 축을 보존하면 각각 0/224다. 밀도·압력·에너지와 상 표시는 보존하고 전하축도 스칼라 규약으로 줄이면 각각 138/224다. 이때 각 보간법은 23개, Maxwell은 0개다. 이 276개 결과는 압력곡선의 기하에 관한 수치 시험으로 분류했다. 49점의 후반부 두 번째 밀도프로파일 구역까지 모두 보존한 사례는 없다.

## 3. 별도로 수행한 궤도 HF와 베타평형 시험

- 궤도 Hartree–Fock 계산은 조성, 격자, 초기화를 바꾼 총 208회다. 139회 수렴, 62회 함수 유효범위 내 자기일치 반복 실패, 7회 반복 한도 도달이었다. 인쇄 계수는 기준 격자 96에서 원전 조성과 양쪽 짝수 전하 이웃 33개가 모두 수렴하지 않았다. 다른 초기화와 격자의 44회 중 8회가 수렴했지만, 연속한 세 저밀도점도 볼록성과 제1법칙 필요조건을 통과하지 못했다. 열한 밀도를 잇는 인쇄 계수의 궤도 HF 표는 구성되지 않았다.
- 수정 계수의 기준 전하 3개씩, 총 33개는 모두 수렴했다. 추가 전하 탐색에서 처음 세 밀도의 최소 후보 $Z$가 각각 42→50, 42→47, 42→43으로 바뀌었다. 셀당 총 핵자수 $A$는 고정했다. 확대된 탐색에서 11개 국소 전하 최소점 중 6개만 궤도 점유 경계의 베타평형 구간에 0을 포함했다. 격자 96→160에서 압력 변화는 최대 5.93%다. 기준 삼중항에서 뽑은 11점의 실제 화학퍼텐셜로는 0/224, 동일 $n,P,\varepsilon$를 스칼라로 줄이면 138/224였다. 사후 전하 탐색 결과와 접합에 사용한 기준 입력은 각각 별도 표에 있다.
- 별도 균일물질 계산은 같은 벌크 에너지를 양성자분율에 대해 최소화했다. $2.79\times10^{-4}\le n_B\le0.0789\,\mathrm{fm}^{-3}$의 257개 밀도점에서 최대 베타평형 잔차는 $1.93\times10^{-12}\,\mathrm{MeV}$이고 $0.000447\le c_s^2/c^2\le0.01136$이었다. 138/224가 통과했다. 균일상에서는 $D_{03}$을 포함한 밀도 기울기 항이 사라지므로 이 표는 한 번만 셌다. 균일물질에 대한 검산은 비균일 내각의 전역 바닥상태를 확정하지 않는다.

## 4. BPS 외각과 NV1973 내각을 함께 보존하는 조합

BPS 방출점의 $(n_0,\varepsilon_0,\mu_0)$를 고정하고 NV1973 Table 4 **비균일 평형상에 대한 저자 fit**에서 오른쪽 끝점을 골랐다. 두 자료가 공유하는 압력에서 $mu_{\rm NV}-\mu_{\rm BPS}$는 +0.31340에서 +0.16627 MeV로 줄어든다. 이 구간에서 $d(\mu_{\rm NV}-\mu_{\rm BPS})/dP=1/n_{\rm NV}-1/n_{\rm BPS}<0$이므로 공존점이 없다. [NV1973](https://doi.org/10.1016/0375-9474(73)90349-7)

볼록한 연결에는 $H(n)=\varepsilon_0-\varepsilon_{\rm NV}(n)+\mu_{\rm NV}(n)(n-n_0)\ge0$가 필요하다. 첫 두 원전 밀도점 사이에서 $H'=(n-n_0)\mu'_{\rm NV}>0$이고 $H(4.00\times10^{-4})=-2.5591\times10^{-5}\,\mathrm{MeV\,fm}^{-3}$이므로 **그 구간 전체**가 탈락한다. 에너지 영점 이동은 0으로 두었다.

채택된 연결은 $x=(n-n_0)/(n_1-n_0)$에서 $\varepsilon(x)$를 3차 Hermite 함수로 두고 양 끝의 $\varepsilon,\mu=d\varepsilon/dn$를 맞춘 것이다. $P=n\mu-\varepsilon$와 $c_s^2/c^2=n\varepsilon''/\mu$를 같은 함수에서 계산했다. 257점 NV 격자에서 곡률 양수와 전 구간 아광속성을 만족하는 첫 점은 38번째 행 $n_1=6.3083914055\times10^{-4}\,\mathrm{fm}^{-3}$이다. $n_1/n_0=2.43858$, 전 구간 $c_s^2/c^2\le0.00306108$이다. 두 끝 사이에는 원전에서 채취한 세 저밀도 셀 위치가 들어간다. 이 구간의 EOS는 보간 가정이다.

결합표 906행은 BPS 원천 재구성 623행, 보간 내부 63행, 저자 fit에서 직접 보존한 220행으로 이루어진다. 상 번호 201–212는 BPS, 213은 보간, 214는 NV fit이다. 이 표를 코어와 접합한 138개 수치해 중 115개는 BPS 12개 상, 보간 구간, NV fit과 코어를 모두 포함한다. 115개 모두 906행 전체와 NV fit 220행 전부를 보존한다. 이 중 110개는 선택된 코어 끝까지 이어지고 5개는 코어의 허용된 한 상 구간에 이어진다. 제1법칙 Hermite 및 네 다항식 방법이 각각 23개를 제공한다. 나머지 23개는 CSS가 외각에서 코어로 건너뛴 결과다. 각 조합이 NV를 실제로 몇 행 유지했는지는 COMPOSITE_RETENTION.csv의 공개 수치 열에서 확인할 수 있다.

## 5. 파일과 재현

- 기본 행렬은 `Primary_matching_672.csv`에 있다. 전체 통합 장부는 `remaining_matches/ALL_CELLS.csv`다. 전체 고유 키는 (reconstruction, census_cell_id)이고 원래 세 슬롯의 키는 서로 중복되지 않는다. 총 11개 입력 표현에서 2,464개 조합, 6,016회 원천 구간별 matcher 호출을 실행했다. 추가 1,792개는 원래 672개의 분모에 들어가지 않는다. 원래 검증용 코어와 저자 fit을 다시 연결한 7개 대조군의 결과, 호출 수와 검증 수치도 종전 기록과 일치했다.
- 압축파일에서 `remaining_matches/<입력 이름>/ALL_CELLS.csv`는 방법·코어·실패·보존 상을, `PUBLIC_MATCHED_EOS.zip`은 공개 통과 조합의 CompOSE 표를 담는다. `PUBLIC_MATCHED_ROWS.zip`에는 같은 결과를 일반 CSV로 읽을 수 있게 $n_B,\varepsilon,P$, 상 및 구역을 넣었다. `PUBLIC_RECEIPTS.jsonl.gz`에서 각 공개 결과의 성공·실패와 출처를 추적할 수 있다. 비공개 코어 1개는 총계에 포함하고 공개 배포의 수치 배열에서 제외했다. 모든 통과 수는 유한 구간의 필요조건에 대한 것이며 TOV 또는 Cowling 관측량을 별도로 적분한 결과를 뜻하지 않는다.
- 궤도 계산은 `orbital_hf/`, 원전 계수·방사형 검산은 `source_audit/`, BPS 검산은 `bps_validation/`, 외각–내각의 전 구간 증명 및 원천 행 수는 `supplementary_bps_nv/bridge_verification.json`에 있다. 고정조성 및 균일 가지의 원 표와 검산은 `nv_profiles/`에 있다. 압축파일의 `REPLAY.md`에 실행 진입점과 기준 버전을 적었다.
- 현재 계산에 추가 제공할 논문은 없다. 정확한 역사적 질량표와 행별 대조를 원할 때만 Myers–Świątecki의 **Lawrence Radiation Laboratory Report UCRL-11980, Appendix D, 1965-05-27**이 필요하다. 그 보고서의 별도 DOI는 확인되지 않았다. NV의 실제 원 피팅 가중치와 계수 수정 의도를 인증하려면 저자 계산 덱이나 정정표가 필요하며 확인된 별도 DOI는 없다. 위 세트의 참조 가능 문헌은 이미 계산에 반영했다.

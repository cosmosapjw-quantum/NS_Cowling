## 같은 표에서 읽은 값과 미분이 왜 서로 어긋날까?

압력과 첫 미분이 연속인 cubic을 이어 붙였다. 둘째 미분도 연속인가? 압축응답의 knot를 물질적 밀도 jump로 읽어도 되는지 먼저 적자.

먼저 한두 문장으로 답한 뒤 아래 설명을 읽자. 첫 예측이 틀렸거나 아직 모르겠다고 적는 것은 감점하지 않는다.

## 필요한 관계와 읽을 위치

$n=P_{,t}/H,\ \epsilon=\mu n-P,\ \chi=H P_{,t}/(\mu P_{,tt}),\ dr/dx=H/(\mu\nu')$.

- `notes/chapters/ch09.md`
- `methods/src/eos/ns_cell_eos.f90`
- `methods/src/eos/ns_table_eos.f90`
- `calculation/tests_fortran/cell_checks.f90`

## 계산으로 옮기기

제공 함수의 호출이 기본 경로다. 구간 보간·역함수·적응 적분·matching의 내부 코드를 작성하지 않고, 입력 조건과 반환된 근거를 해석한다.

1. P와 첫 미분의 연속성을 둘째 미분의 연속성과 구분한다.
2. 무차원 P=mu^2와 좁은 구간 예제에서 제공 cell_state·역함수를 호출한다.
3. calculation의 cell_checks를 실행하고 12개 관계가 의미하는 범위를 적는다.
4. 다른 t와 구간 폭에서 제1법칙과 SI 차원을 손계산으로 확인한다.

## 결과를 설명하기

평가할 대상은 하나의 구간 함수다. Native knot를 보존하고 작은 local coordinate에서 값·미분·역함수를 확인한다. 표를 더 조밀하게 만든 것과는 다르다.

**남길 증거.** 한 구간의 P,n,epsilon,chi 유도; local t 역함수와 절대 mu subtraction 비교; 선택 workspace의 실제 검사 기록

**판단 기준.** 2점: 계수 jump와 새로운 물질적 jump를 구분하고, 각 미분의 H 차수와 pressure residual을 설명한다. 최초 예측의 정오보다, 결과를 본 뒤 이유를 고치고 다른 입력에도 적용하는지를 본다.

## 막혔을 때

**힌트 1.** 미분할 때 t의 단위와 H 인자를 확인한다.

**힌트 2.** P-a0와 t(a1+t(a2+a3t))를 비교하면 작은 차이를 절대 mu로 되돌리지 않아도 된다.
